🔐 จัดการสิทธิ์เจ้าของระบบเพียงผู้เดียว (Single-Owner Lockdown)

เปลี่ยนอีเมลเจ้าของระบบหรือเปลี่ยนรหัสผ่าน Master Admin (เข้ารหัส SHA-256 + Random Salt ใหม่ทุกครั้ง)

• หากคุณล็อกอินหน้าเว็บด้วย Google / Facebook / Email อีเมลที่ล็อกอินจะต้องตรงกับอีเมลเจ้าของระบบด้านบนเท่านั้นจึงจะเปิดหน้าแอดมินได้

• หากกรอกรหัสผ่านผิดติดต่อกัน 3 ครั้ง ระบบจะล็อกการเข้าถึงอัตโนมัติ 60 วินาที

🔥 เชื่อมต่อ Firebase Authentication & Firestore (ใช้งานจริงบน GitHub Pages)

เมื่อวางค่า Firebase Config ระบบจะสลับจากการจำลองไปใช้ Google Sign-In, Facebook Login และฐานข้อมูล Cloud จริงทันที

ยังไม่ได้ใส่ Config (ทำงานโหมดจำลอง)

📘 คู่มือ 4 ขั้นตอนเปิดใช้ Google & Facebook Login ฟรีบน GitHub Pages:

  1. ไปที่ console.firebase.google.com สร้างโปรเจกต์ฟรี และเพิ่ม Web App เพื่อคัดลอกค่า firebaseConfig มาวางในช่องด้านบน
  2. เข้าไปที่เมนู Authentication → Sign-in method เปิดใช้งาน Google, Facebook (ใส่ App ID & App Secret จาก Meta for Developers) และ Email/Password
  3. ในหน้า Authentication → Settings → Authorized domains กดเพิ่มโดเมน GitHub Pages ของคุณ เช่น username.github.io
  4. ไปที่เมนู Firestore Database กดสร้างฐานข้อมูล เพื่อเก็บบันทึกข้อมูลผู้ใช้งานแบบเรียลไทม์ให้แอดมินดูได้จากทุกเครื่อง
